Necessary Classes
-	Shader Manager
	o	Stores shaders in map by name or type?
	o	Stores shader related modules in map by name or type?
	o	Provides access to shaders/modules for render passes
-	Geometry Manager
	o	Mesh Cache: Stores GPU-ready meshes to avoid recreating buffers for multiple instances.
	o	Scene Graph: Maintains hierarchical scene structure (transforms, parents/children).
	o	Render Loop Logic: Determines what shader/material to use per object when rendering, usually through the material.
-	File Handler: 
	o	Scans directories for assets (images, meshes, JSON/BSON, etc.).
	o	maintains maps of file paths for fast retrieval.
	o	Stores vectors of char* for ImGui asset selectors
-	Image Manager: 
	o	Loads textures/images form disk via file handler
	o	Stores GPU texture resources;
	o	Provides access to textures for shaders/materials;
-	Material Manager
	o	Stores and allows creation of object materials
	o	Materials hold Colour, Specular and shader data. 
-	Render Pass Manager:
	o	Manages different render passes, each doing a specific task?
		?	Geometry Pass
		?	Lighting Pass
		?	Shadow Pass
		?	Post-Processing pass
	o	Each render pass has
		?	References to shaders/modules it uses
		?	ASccess to RenderCache or other resources
		?	Render targets/depth buffers
		?	Responsible for rendering passes in correct order
-	ImGui Manager
	o	Managed ImGui rendering and controls?
-	Serializer:
	o	Serializes and parses scene data.
